Security — Master PIN
Required to delete records and to mark records as reviewed. This is a shared deterrent PIN, not encryption — anyone with edit access to this artifact's code could bypass it, so don't treat it as a strong security control.
Security — User PINs
Assign a personal PIN to each production team member who's allowed to edit or delete records. Their PIN identifies them for the audit trail — no more relying on a self-typed name. Visible here to you as admin so you can hand PINs out; not shown anywhere else in the form.
